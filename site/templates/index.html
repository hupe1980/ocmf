The rule everything else follows from

The signature is ECDSA over SHA-256 of the payload section exactly as it was written. Parse into a struct, serialise it back, and the hash has already changed.

Key order, whitespace, number formatting and Unicode escapes are all free to change on a round trip through a typed value — and every one of them changes the digest. So Record::signed_bytes() returns a slice of the input, and no API in this crate produces signable bytes from a typed value.

Nine records in the reference corpus are pretty-printed. Any implementation that re-serialises destroys them.

What it does

One crate for the whole life of a record: read it, judge it, check it, produce it, move it.

Reads what meters emit

Every record in the S.A.F.E. reference corpus parses and reproduces itself byte for byte — padded quoted numbers, unpadded DER integers, bare public keys and all.

Says how it deviates

Every departure from the specification is a typed value with the table it is measured against, and a flag saying whether it breaches the document or is merely worth knowing.

Verifies all seven algorithms

Four curves in pure Rust, all seven through OpenSSL. An algorithm a build cannot check is reported as unsupported, never as “does not verify”.

Signs, safely by default

RFC 6979 deterministic ECDSA — no nonce, no RNG — low-s output, an HSM seam, and every record re-read and re-verified before it is returned.

Checks a whole session

Continuous pagination, one begin and one end in their places, one source, error states fatal: every rule the specification assigns to a check component.

Moves it, both ways

OCPP’s SignedMeterValueType with the oca: key composition, and a S.A.F.E. transparency file grouped into the transactions its verifier pairs on.

Runs where the meter is

#![no_std] with alloc, #![forbid(unsafe_code)], no I/O, no clock and no randomness — so it builds for a charge controller and for wasm32 alike.

Written from the data, not only from the document

Every design decision is anchored in a measurement over 256 real records from eleven vendors, each carrying OpenSSL’s independent verdict.

89 % of real records omit a field the specification marks mandatory. A strict parser rejects nine records in ten; a lenient one never tells an operator their fleet emits records the official tool will reject. So parsing runs in a profile, and every departure is reported rather than swallowed.

Twenty-six of those records carry a value no closed table defines — a unit called sec, a charge-point identifier written as a JSON number, RFID UIDs of the wrong width. They parse clean everywhere else.
